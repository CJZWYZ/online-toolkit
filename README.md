# 在线小工具箱 🧰

一个纯前端、零依赖的在线小工具集合，所有计算都在你的浏览器本地完成，数据不会上传到任何服务器。

## 包含工具

- 🔑 **密码生成器**：可调长度与字符类型，带强度提示
- 📐 **单位换算**：长度 / 重量 / 温度实时换算
- ⏱️ **番茄钟**：专注 / 休息计时
- 🎨 **颜色工具**：取色并输出 HEX / RGB / HSL

## 技术栈

纯 `HTML + CSS + 原生 JavaScript`，无需任何构建步骤或第三方依赖。

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动一个静态服务：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署

已配置 GitHub Pages，仓库根目录的 `index.html` 即为站点入口。
