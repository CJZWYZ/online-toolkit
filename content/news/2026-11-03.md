今天的两条主线，一条是「模型能力继续外溢到自主可控与产品化」，一条是「资本在狂热与纪律之间重新找平衡」。美团用全国产算力训出 1.6 万亿参数的 LongCat-2.5，把「国模国芯」从口号推进到可落地的工作流；同一时间，OpenAI 与 Anthropic 的下一代旗舰被开发者从代码里「抓包」提前曝光，模型竞赛正从发布会走向「源码泄露」式的贴身肉搏。产品侧，OpenAI 的 Decisions API、Canva 的自研图像模型、Claude 在 Google Cloud 的整机交付，都在把 AI 从「会聊天」推向「能决策、能交付」；资本侧，OpenAI 把融资目标从 300 亿砍到 200 亿美元，中东主权基金却逆势加注，可灵、Agility 等接连拿到上市或巨额融资的船票。技术纵深上，微软 MAI-DxO 以「五位虚拟医生会诊」登 Science，诊断准确率超人类医生一倍多——能力扩散的边界，正在被一次次刷新。

## 大模型与 AI 产品发布

**美团发布 LongCat-2.5：1.6 万亿参数、全程国产算力训练的原生多模态模型。** 11 月 2 日，美团发布面向长程智能体任务的 LongCat-2.5，总参数 1.6 万亿，训练全程由国产算力完成，原生支持多模态与百万 token 长上下文，并强化了智能体编程与商业分析能力。官方称其多项主流基准介于 Claude Opus 4.8 与 Opus 5 之间、部分超过 Opus 5，基于该模型的 AI 经营工作台「妙手」已服务古茗、益禾堂等连锁品牌。详见 [美团发布1.6万亿参数大模型，全国产算力训练（观察者网）](https://www.toutiao.com/article/7703497526016328255)。

**下一代旗舰同日「曝光」：GPT-6.2 Astra 与 Claude Mythos 5.5 提前泄露。** 11 月 1 日晚，有开发者在调试 Codex 时发现底层接口已从 GPT-6 Astra 换为 gpt-6.2-astra，账单显示新模型已吃下约两成真实流量；同期有人在 Anthropic 官网源码中扒出尚未公布的 Claude Mythos 5.5（高风险研究向）及面向大众的 Fable 5.5 字样。两款新模型均未官宣，爆料称 GPT-6.2 可自起子进程连续工作数小时、Mythos 5.5 曾在 53 分钟内独立攻破 Linux 内核，属于「源码露馅」而非正式发布。详见 [OpenAI、Claude新旗舰同日曝光（新浪财经 / 新智元）](https://www.toutiao.com/article/7703348414712513051/)。

**Canva 发布首款自研图像模型 Canva Craft。** Canva 推出由内部研究院从零训练的图像生成模型 Craft，采用「先规划构图、再渲染成像」的两阶段架构，最高支持 2K 分辨率、30 多种宽高比，并可在 Canva 内转为可编辑图层。Canva 称其在 DesignArena 综合排名第四、人物与风景品类居首，并计划通过 MCP 接入 ChatGPT、Gemini 等外部助手；自研意在降低对外部 API 的依赖与成本。详见 [Introducing Canva Craft（Canva 官方）](https://www.canva.com/newsroom/news/canva-craft/)。

**OpenAI 将 Decisions API 转为正式可用，用 GPT-6 Luna 把应用决策提速 10 倍。** Decisions API 面向「答案有限的小决策」（分类、路由、打分），基于 GPT-6 Luna，相较通过 Responses API 调用 Luna 提速最高 10 倍，支持图像与原生 JSON 输入、单次最多 400 个问题，并新增 GPT-Live 原生集成与美欧推理驻留。Box、Datadog、Ramp、Sierra 等已在文档路由、风险评分、成本归因等场景落地。详见 [Build more responsive apps with the Decisions API（OpenAI 官方）](https://openai.com/index/decisions-api)。

## 平台、生态与开源

**Claude Platform 在 Google Cloud 全面可用，做到「首日功能对等」。** Anthropic 运营的 Claude Models on Google Cloud（Anthropic managed）正式 GA，Google Cloud 客户可用自有 IAM 鉴权与 Marketplace 账单，用量计入既有 GCP 承诺消费，新功能与测试版与原生 Claude Platform 同日上线。该服务包含 Managed Agents、代码执行、Computer Use、Agent Skills、Advisor、MCP 连接器等完整能力，Opus 5.5 Fast Mode 也同步可用，为已在 GCP 有采购承诺的企业提供「不拆账单、不换身份」的接入路径。详见 [The full Claude Platform, available on Google Cloud（Claude 官方）](https://claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed)。

**Anthropic 把 Agent Skills 开放标准捐给 Linux 基金会。** Anthropic 将 Agent Skills（用含 SKILL.md 的文件夹为智能体封装可复用工作流与领域知识）捐赠给 Linux 基金会旗下的 Agentic AI Foundation，同期 OpenAI、Hugging Face、阿里分别贡献 Open Responses、OpenEnv、OpenSandbox，AAIF 项目数一年内从 3 增至 10。Anthropic 称已有 ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 多个平台集成该标准，累计发布约 100 万项技能、安装近 2.8 亿次，捐赠意在让它成为厂商中立、社区共治的「智能体操作层」基础设施。详见 [Donating Agent Skills to the Agentic AI Foundation（Anthropic 官方）](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)。

## 融资、并购与出海

**OpenAI 把最新一轮融资目标下调至 200 亿美元，估值 1.25 万亿、中东领投。** 据 FT 与 WSJ，因科技股抛售与部分大投资者认购收缩，OpenAI 将本轮融资目标从 300 亿降至约 200 亿美元、估值由 1.4 万亿下调至 1.25 万亿美元，首次交割预计不足 200 亿，由阿联酋多家投资机构组成的财团领投，并附带租赁当地新建算力的权利。在 Anthropic 冲刺 IPO 吸走注意力与资本之际，OpenAI 一边收敛雄心、一边用零售发售把本轮规模顶到约 200 亿。详见 [AI巨头大动作！OpenAI大幅下调融资目标（证券时报 / 网易）](https://www.163.com/dy/article/LAKQKE1B05568W0A.html)。

**沙特阿美入股 AI 公司 HUMAIN 49%，石油巨头正式落子 AI 算力。** 11 月 1 日，沙特阿美宣布持有沙特 AI 公司 HUMAIN 49% 股份（PIF 保留其余 51%），今年将向其注入约 99 亿沙特里亚尔（约合人民币 175 亿元）及资产，用于扩充算力基础设施与数字化资产。这是传统能源巨头把「石油美元」转向 AI 基建的又一信号，中东正从算力买家升级为模型与基础设施的股东。详见 [沙特阿美入股AI公司 石油巨头布局算力（央视财经 / 中国能源网）](https://www.toutiao.com/article/7703393685190312484/)。

**OpenAI 与阿布扎比签署能源、政务、投资多项合作，扎根中东。** 奥特曼会见阿布扎比王储，敲定多行业落地 OpenAI 大模型的一系列安排：ADNOC 与 G42 将在油气业务内部署前沿 AI，穆巴达拉、Inception42 将高级 AI 用于投资分析，阿布扎比政府则把政策法规转为机器可读格式。本轮合作叠加 OpenAI 正争取的 200 亿美元中东领投融资，显示海湾国家打造 AI 枢纽的愿景正与美方科技巨头深度绑定。详见 [OpenAI进一步扎根阿布扎比（环球市场播报 / 新浪财经）](https://www.toutiao.com/article/7703544236872745512/)。

**快手可灵 AI 完成约 198 亿元增资，冲刺港股 IPO。** 10 月 30 日晚，快手公告旗下视频生成大模型可灵 AI 完成本轮增资交割，实际到账约 198.02 亿元（约 29.05 亿美元），创全球视频生成大模型单轮融资最高纪录，投后估值约 179 亿美元、超过母公司快手港股市值。金蝶、国产 GPU 厂商沐曦等产业方首次入股并获回购权，资本与算力在股东层面直接绑定；公司被一份对赌协议推着走向 IPO。详见 [198亿！全球视频大模型最大单笔融资诞生（独角兽早知道 / 网易）](https://www.163.com/dy/article/LAL91U5Q0519VPHD.html)。

**Agility Robotics 拟 SPAC 登陆纳斯达克，剑指「人形机器人第一股」。** 人形机器人公司 Agility 与 Churchill Capital XI 的合并预计 11 月 4 日完成，募资约 4.65 亿美元（含富士康牵头的 2.01 亿 PIPE），合并后股票 11 月 5 日以「AGLT」在纳斯达克交易，有望成为美国唯一已商业部署的人形机器人纯标的。其 Digit 机器人已积累超 6.5 万小时真实运行，并与 GXO、AGCO 等签下付费部署，订单储备超 3 亿美元。详见 [Agility Robotics 与 Churchill XI 合并公告（Agility 官方）](https://www.agilityrobotics.com/content/agility-robotics-and-churchill-capital-corp-xi-announce-expected-gross-capital-raise-of-approximately-465-million-and-anticipated-closing-of-business-combination)。

## 关键技术进展

**微软 MAI-DxO 诊断 AI 登 Science：准确率超医生一倍多、成本减半。** 微软在《Science》发表 MAI-DxO（诊断协调器），让同一个底层模型扮演五位「虚拟医生」——提出假设、选择检查、专门挑刺、控制花费、复核推理——像会诊小组一样多轮推进诊断。在 NEJM 304 个疑难病例上准确率达 83.2%（医生约 36%），急诊病例 80.3%（医生约 47%），且成本更低的配置仍优于人类；微软已与贝斯以色列女执事医疗中心合作，准备在真实患者身上验证。详见 [Microsoft MAI-DxO Diagnosis Study（Science, DOI: 10.1126/science.aeh7933）](https://doi.org/10.1126/science.aeh7933)。
